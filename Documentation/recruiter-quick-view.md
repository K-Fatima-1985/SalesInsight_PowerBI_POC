# Recruiter Quick View

## Project in one line

Interactive Power BI Sales Insight Dashboard for analyzing revenue, quantity, profitability, customers, products and market performance.

## Primary Tools

**Power BI | Power Query | DAX | Excel/Tabular Data | GitHub**

## Key Capabilities

- KPI dashboards
- Revenue and profit analysis
- Previous-year comparison
- Market contribution
- Top customer/product analysis
- Interactive slicers
- Business-focused visual storytelling

## Suggested Resume Project Bullet

**Sales Insight Dashboard | Power BI, DAX, Power Query**
- Developed an interactive Power BI sales dashboard covering revenue, sales quantity, profit margin, customer/product performance and market contribution.
- Built DAX measures and interactive filters to support KPI monitoring, contribution analysis and year-over-year performance comparison.
- Applied Power Query transformations and data-quality checks to prepare source data for business analysis.
