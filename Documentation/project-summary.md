# Project Summary

## Project

**Sales Insight Dashboard – Power BI POC**

## Role

**Power BI Developer / Data Analyst – Portfolio POC**

## Objective

Build an interactive sales analytics dashboard that converts raw sales information into business-focused insights.

## Dashboard Areas

### Key Insights
High-level sales performance, revenue trends, products, customers and market analysis.

### Profit Analysis
Revenue, sales quantity, profit margin and contribution analysis across markets and customers.

### Performance Insights
Performance comparison, previous-year revenue, profit margin and market contribution.

## Workflow

**Source Data → Power Query → Data Model → DAX → Visualizations → Business Insights**

## Skills Demonstrated

- Power BI
- Power Query
- DAX
- Data cleaning
- Data modeling
- KPI development
- Time-based analysis
- Top-N analysis
- Interactive filtering
- Business storytelling

## Recruiter Talking Points

### What problem did you solve?

I created an interactive sales dashboard to help users monitor revenue, sales quantity, profitability and contribution across products, customers and markets.

### What did you do in Power Query?

I prepared the data by checking data types, cleaning fields, handling data-quality issues and preparing the dataset for analysis.

### What did you do with DAX?

I created measures for core KPIs and analytical calculations such as revenue, sales quantity, profit margin, contribution percentages and previous-year comparisons.

### What business value does the dashboard provide?

It allows decision-makers to quickly identify high-performing products, customers and markets, understand revenue/profit trends and compare performance.
